CADA ACL   access-list N   deny   tipo   host QUIÉN   host DESTINO   eq PUERTO
ping = icmp, sin puerto.   página = tcp eq 80.   DNS = udp eq 53 y también tcp eq 53.
deny corta solo esa línea.   Al final, una vez: permit ip any any
La 1ª IP es la PC → router de esa sede, interfaz del .100, in.
Si dice any → router de la 2ª IP, interfaz del .100, out.
Mismo router y mismo sentido = una sola lista. Otra in pisa la anterior.
En la interfaz:   ip access-group NOMBRE in    o    ip access-group NOMBRE out
EJEMPLO IN   20.80.20.2 no abre la web 20.80.30.50 → router Corrientes, in
deny tcp host 20.80.20.2 host 20.80.30.50 eq 80
permit ip any any
EJEMPLO OUT   nadie de afuera pingea a 20.80.20.101 → Corrientes, out
deny icmp any host 20.80.20.101
permit ip any any
PC y servidor de la misma sede no pasan por el router: la ACL no los ve.
