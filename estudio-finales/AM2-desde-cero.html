Análisis II desde cero. Cómo se hace cada ejercicio, paso por paso.

Orden recomendado: primero la sección 0 (lo que hay que saber de antes), después una receta por día. Cuando una receta te salga sin mirar, pasá a AM2.html a hacer los del final.

Derivada parcial: la otra letra es un número

Para derivar respecto de x, hacé de cuenta que y es un número fijo (como si fuera 5). Para derivar respecto de y, al revés.

f(x, y) = x²y³ + exy + 3y.

fx: x²y³ → 2x·y³ (y³ es una constante que multiplica). exy → exy · y (regla de la cadena: la derivada de xy respecto de x es y). 3y → 0 (no tiene x). fx = 2xy³ + y exy.

fy: fy = 3x²y² + x exy + 3.

Segundas: fxx es derivar fx otra vez respecto de x; fxy es derivar fx respecto de y. fxy y fyx dan lo mismo (sirve para controlar). Acá: fxx = 2y³ + y²exy; fxy = 6xy² + exy + xy exy.

Para practicar: f = x³y − 2xy² + sen(x)

fx = 3x²y − 2y² + cos x. fy = x³ − 4xy. fxx = 6xy − sen x. fyy = −4x. fxy = 3x² − 4y.

Parametrizar un camino (para las integrales de línea)

Segmento de P a Q: (x, y) = P + t(Q − P), t de 0 a 1. Ejemplo de (1, 0) a (1, 1): x = 1, y = t. Si es horizontal o vertical es más fácil usar directamente la variable que cambia: en el segmento vertical x = 1, y va de 0 a 1, y dx = 0.

Curva y = g(x): usá x como parámetro. y = g(x), dy = g′(x) dx, y x va del valor inicial al final en el sentido del recorrido (si se recorre de derecha a izquierda, la integral va de un número mayor a uno menor).

Circunferencia de radio a: x = a cos t, y = a sen t, dx = −a sen t dt, dy = a cos t dt. Con t creciendo se recorre antihoraria.

1. Función partida en el origen (ejercicio 1)

Te dan algo como f(x, y) = (fórmula) si (x, y) ≠ (0, 0), y f(0, 0) = 0. Te preguntan, en este orden: continuidad, derivadas parciales en el origen, diferenciabilidad, y a veces derivada direccional. Todo se hace en (0, 0) y todo por definición: en el origen la fórmula no vale, así que no se puede derivar con las reglas.

Abajo, cada paso tiene su explicación, un ejemplo con todas las cuentas (recuadro gris) y cómo se escribe en la hoja (recuadro verde).

Paso 0. Mirar los grados (un minuto, en borrador)

El grado de un término es la suma de los exponentes de x y de y. El grado del numerador es el del término más chico (el que manda cerca del origen). √(x² + y²) cuenta como grado 1. Después comparás: grado de arriba − grado de abajo.

Diferencia 0 o negativa → no continua. Diferencia 1 → continua y casi siempre no diferenciable. Diferencia 2 o más → diferenciable. Esto no se escribe en el examen: te dice qué tenés que demostrar.

Paso A. Continuidad

Se demuestra que lím(x,y)→(0,0) f(x, y) = f(0, 0). Según lo que te dijo el paso 0, vas por uno de dos caminos.

A1. Si esperás que NO exista: caminos

Reemplazás y por una expresión en x (una recta, una parábola) y te queda un límite de una sola variable. Si dos caminos dan resultados distintos, el límite doble no existe.

Ejemplo: f = xy/(x² + y²).

Recta y = mx. Reemplazo cada y por mx:

f(x, mx) = x · mx / (x² + (mx)²) = m x² / (x² + m² x²).

Saco factor común x² abajo: m x² / [x²(1 + m²)]. Simplifico x²: m/(1 + m²).

No queda x: el límite por esa recta es m/(1 + m²). Depende de m: con m = 0 da 0; con m = 1 da 1/2.

Tomo el camino y = mx: límx→0 f(x, mx) = límx→0 m x²/(x²(1 + m²)) = m/(1 + m²). El límite depende de m, es decir, de la recta por la que me acerco. Por lo tanto lím(x,y)→(0,0) f(x, y) no existe y f no es continua en (0, 0).

Cuando las rectas dan todas lo mismo: f = x²y/(x⁴ + y²).

y = mx: x²·mx/(x⁴ + m²x²) = m x³/[x²(x² + m²)] = m x/(x² + m²) → 0 cuando x → 0. Todas las rectas dan 0. No alcanza para decir que existe.

Pruebo la parábola y = x² (elegida para que x⁴ e y² tengan el mismo grado): x²·x²/(x⁴ + x⁴) = x⁴/(2x⁴) = 1/2.

Por rectas 0, por la parábola 1/2: no existe.

Los ejes son los caminos más fáciles: y = 0 (reemplazás y por 0) y x = 0. Con f = (x³ − y²)/(x² + y²): por y = 0 da x³/x² = x → 0; por x = 0 da −y²/y² = −1. Distintos: no existe.

A2. Si esperás que SÍ exista: polares y acotación

Los caminos nunca prueban que existe (hay infinitos caminos). Se prueba con una cota: |f(x, y) − 0| ≤ (algo que tiende a 0).

Receta: (1) reemplazar x = r cos θ, y = r sen θ; (2) el denominador x² + y² se hace r² (porque cos²θ + sen²θ = 1) y √(x² + y²) se hace r; (3) simplificar las r; (4) acotar lo que depende de θ usando |cos θ| ≤ 1, |sen θ| ≤ 1 y |a + b| ≤ |a| + |b|; (5) concluir.

Ejemplo: f = 3xy²/(x² + y²).

(1) Numerador: 3 · (r cos θ) · (r sen θ)² = 3 · r cos θ · r² sen²θ = 3r³ cos θ sen²θ.

(2) Denominador: r² cos²θ + r² sen²θ = r²(cos²θ + sen²θ) = r².

(3) f = 3r³ cos θ sen²θ / r² = 3r cos θ sen²θ.

(4) |cos θ| ≤ 1 y sen²θ ≤ 1, así que |3 cos θ sen²θ| ≤ 3. Entonces |f| ≤ 3r.

(5) Cuando (x, y) → (0, 0), r → 0, y 3r → 0.

Paso a polares: x = r cos θ, y = r sen θ, con r = √(x² + y²). f(r cos θ, r sen θ) = 3r cos θ sen²θ. Como |cos θ sen²θ| ≤ 1 para todo θ: 0 ≤ |f(x, y) − 0| ≤ 3r → 0. Por el teorema de intercalación lím(x,y)→(0,0) f(x, y) = 0 = f(0, 0). Por lo tanto f es continua en (0, 0).

Con raíz abajo: f = xy/√(x² + y²). Numerador r² cos θ sen θ, denominador √(r²) = r. f = r cos θ sen θ, |f| ≤ r → 0. Continua.

Con varios términos: f = (xy² − 2y³)/(x² + y²) = r(cos θ sen²θ − 2sen³θ). Para acotar el paréntesis: |cos θ sen²θ − 2sen³θ| ≤ |cos θ sen²θ| + 2|sen³θ| ≤ 1 + 2 = 3. Entonces |f| ≤ 3r.

Sin polares (también vale): como x² ≤ x² + y², sale |x| ≤ √(x² + y²) y y²/(x² + y²) ≤ 1. Entonces |3xy²/(x² + y²)| = 3|x| · y²/(x² + y²) ≤ 3|x| → 0.

La trampa: si al pasar a polares no queda ninguna r, por ejemplo (x² − y²)/(x² + y²) = cos²θ − sen²θ = cos 2θ, el resultado depende del ángulo: el límite no existe.

Último detalle: si el límite existe pero f(0, 0) está definido con otro número (por ejemplo f(0, 0) = 1 y el límite da 0), tampoco es continua.

Paso B. Derivadas parciales en el origen, por definición

Las fórmulas son siempre éstas. Lo único que cambia es cuánto valen f(h, 0) y f(0, k):

fx(0, 0) = límh→0 [f(h, 0) − f(0, 0)] / h    fy(0, 0) = límk→0 [f(0, k) − f(0, 0)] / k

Receta: (1) calcular f(h, 0): en la fórmula, cada x se cambia por h y cada y por 0. (2) Restar f(0, 0) (que casi siempre es 0). (3) Dividir por h. (4) Hacer h → 0. Lo mismo con f(0, k): x por 0 e y por k.

Ejemplo: f = (xy² − 2y³)/(x² + y²).

f(h, 0) = (h · 0² − 2 · 0³)/(h² + 0²) = 0/h² = 0. Entonces [0 − 0]/h = 0 y fx(0, 0) = 0.

f(0, k) = (0 · k² − 2k³)/(0² + k²) = −2k³/k² = −2k. Entonces [−2k − 0]/k = −2 y fy(0, 0) = −2.

fx(0, 0) = límh→0 [f(h, 0) − f(0, 0)]/h = límh→0 (0 − 0)/h = 0.

fy(0, 0) = límk→0 [f(0, k) − f(0, 0)]/k = límk→0 (−2k − 0)/k = −2.

Cuando una parcial no existe: f = √(x² + y²) (el cono). f(h, 0) = √(h²) = |h|. El cociente |h|/h vale 1 si h > 0 y −1 si h < 0: los límites laterales son distintos, fx(0, 0) no existe. Y entonces f no es diferenciable.

Paso C. Diferenciabilidad, por definición

f es diferenciable en (0, 0) si este límite vale 0:

lím(h,k)→(0,0) [f(h, k) − f(0, 0) − fx(0, 0)·h − fy(0, 0)·k] / √(h² + k²)

Receta: (1) escribir el cociente con los números de tus parciales; (2) pasar a polares: h = r cos θ, k = r sen θ, √(h² + k²) = r; (3) simplificar; (4) si queda r por algo acotado → el límite es 0 → diferenciable; si no queda r y depende de θ → mostrar dos ángulos con resultados distintos → no diferenciable.

Ejemplo con las parciales en 0: f = 3xy²/(x² + y²), fx = fy = 0.

(1) [f(h, k) − 0 − 0·h − 0·k]/√(h² + k²) = f(h, k)/√(h² + k²).

(2) y (3) Del paso A ya sé que f = 3r cos θ sen²θ. Dividido r: 3 cos θ sen²θ.

(4) No hay r. Pruebo ángulos: θ = 0: 3 · 1 · 0 = 0. θ = π/4: 3 · (√2/2) · (1/2) = 3√2/4. Dos valores distintos.

Analizo lím(h,k)→(0,0) [f(h, k) − f(0, 0) − fx(0,0)h − fy(0,0)k]/√(h² + k²) = lím f(h, k)/√(h² + k²). En polares: 3r cos θ sen²θ / r = 3 cos θ sen²θ, que depende de θ (vale 0 en θ = 0 y 3√2/4 en θ = π/4). El límite no existe, entonces no es 0, y f no es diferenciable en (0, 0).

Ejemplo con una parcial distinta de 0: f = (xy² − 2y³)/(x² + y²), fx = 0, fy = −2.

(1) [f(h, k) − 0 − 0·h − (−2)·k]/√(h² + k²) = [f(h, k) + 2k]/√(h² + k²). Ojo con el signo: menos por menos da más.

(2) f = r(cos θ sen²θ − 2sen³θ) y 2k = 2r sen θ.

(3) [r(cos θ sen²θ − 2sen³θ) + 2r sen θ]/r = cos θ sen²θ − 2sen³θ + 2sen θ.

(4) θ = 0 → 0. θ = π/4 → √2/4 − √2/2 + √2 = 3√2/4. No es diferenciable.

Ejemplo que SÍ es diferenciable: f = x²y²/(x² + y²), parciales 0.

f en polares: r⁴cos²θ sen²θ/r² = r² cos²θ sen²θ. Dividido r: r cos²θ sen²θ. Queda una r: |r cos²θ sen²θ| ≤ r → 0. El límite es 0: es diferenciable.

Atajos que podés escribir: “f no es continua, entonces no es diferenciable” (diferenciable implica continua). “fx(0,0) no existe, entonces no es diferenciable”. “Las parciales son continuas en un entorno, entonces es diferenciable” (casi nunca aplica en el origen).

Paso D. Derivada direccional en el origen

Duf(0, 0) = límt→0 [f(ta, tb) − f(0, 0)] / t, con u = (a, b) unitario

Receta: (1) verificar que u es unitario (a² + b² = 1); si no, dividirlo por su largo; (2) calcular f(ta, tb): cada x se cambia por ta y cada y por tb; (3) sacar factor común las t, usar a² + b² = 1; (4) dividir por t y hacer t → 0.

Ejemplo: f = 3xy²/(x² + y²) en la dirección de v = (1, 2).

(1) ‖v‖ = √(1 + 4) = √5. u = (1/√5, 2/√5).

(2) Con u = (a, b) general: f(ta, tb) = 3(ta)(tb)²/((ta)² + (tb)²) = 3t³ab²/[t²(a² + b²)].

(3) a² + b² = 1, así que f(ta, tb) = 3t ab².

(4) [3t ab² − 0]/t = 3ab². Con a = 1/√5, b = 2/√5: 3 · (1/√5) · (4/5) = 12/(5√5) ≈ 1,07.

Si f fuera diferenciable daría ∇f · u = 0. Da otra cosa: es otra forma de probar que no es diferenciable.

u = v/‖v‖ = (1/√5, 2/√5). Duf(0, 0) = límt→0 [f(t/√5, 2t/√5) − 0]/t = límt→0 3t·(1/√5)(4/5)/t = 12/(5√5).

Ejemplo hecho (es el del final de 2026). f(x, y) = 3xy²/(x² + y²) si (x, y) ≠ (0, 0), f(0, 0) = 0.

Grados: numerador 3, denominador 2. Numerador mayor: va a ser continua. Supera solo en 1: sospecho que no es diferenciable.

A. Continuidad. Polares: f = 3 r cos θ · r² sen²θ / r² = 3r cos θ sen²θ. Como |cos θ sen²θ| ≤ 1, |f| ≤ 3r → 0. El límite es 0 = f(0, 0): es continua.

B. Parciales. f(h, 0) = 3h·0/h² = 0, así que fx(0,0) = lím (0 − 0)/h = 0. f(0, k) = 0, fy(0,0) = 0.

C. Diferenciabilidad. El cociente es f(h, k)/√(h² + k²) = 3r cos θ sen²θ / r = 3 cos θ sen²θ. No tiene r: depende de θ. Por ejemplo en θ = 0 da 0 y en θ = π/4 da 3·(√2/2)·(1/2) = 3√2/4. No hay un único límite: no es diferenciable.

D. Direccional en u = (a, b). f(ta, tb) = 3·ta·t²b²/(t²a² + t²b²) = 3t ab² (porque a² + b² = 1). Dividido t: 3ab². Duf(0,0) = 3ab²: existe en todas las direcciones. Fijate que no coincide con ∇f · u = 0: es otra forma de ver que no es diferenciable.

Hacelo vos. f(x, y) = x²y/(x² + y²) si (x, y) ≠ (0, 0), f(0, 0) = 0. Los cuatro pasos, con u = (1/√2, 1/√2).

1.er parcial A1, 13/05/2020, ejercicio 1. f(x, y) = (x³ − y²)/(x² + y²), f(0, 0) = 0. ¿Es continua? ¿Es diferenciable?
Resolución por pasos (el caso en que NO es continua)

Paso 0. El término −y² tiene grado 2, igual que el denominador: sospecho que el límite no existe.

Te piden extremos de f(x, y) sujeto a una ecuación (una curva).

4 bis. Regla de la cadena (sale en todos los primeros parciales)

Te dan dos funciones, f y g, y te piden la jacobiana de la compuesta h = f ∘ g (primero g, después f) en un punto x₀, o una derivada de h.

  1. Calculá g(x₀). Ese es el punto donde se evalúa f. Error típico: evaluar f en x₀.
  2. Jacobiana de g en x₀: una fila por cada componente de g, una columna por cada variable.
  3. Jacobiana de f en g(x₀): igual.
  4. Multiplicá h′(x₀) = f′(g(x₀)) · g′(x₀), en ese orden (fila por columna). Controlá tamaños: (m × k)·(k × n) da m × n.
  5. Leé lo que pidan: el elemento (i, j) es ∂hi/∂xj. Si h es real, la fila es ∇h: la direccional es ∇h · u y la máxima razón de cambio ‖∇h‖.

6. Integral de línea: directa y por Green (ejercicio 4)

Te dan ∮C P dx + Q dy sobre el borde de una región, positivamente orientado, y te piden las dos maneras. Tienen que dar lo mismo.

Paso 1. Leer P y Q

P es lo que multiplica a dx; Q lo que multiplica a dy. Si el orden está cambiado o falta uno, reordená.

∮ y dx + 2x dy: P = y, Q = 2x. ∮ x dy − y dx: P = −y, Q = x. ∮ x² dy: P = 0, Q = x².

Paso 2. Dibujo y orientación

Dibujá la región, marcá los vértices, poné flechas en sentido antihorario. Regla: caminando por el borde, la región queda a tu izquierda. Nombrá los tramos (C₁, C₂, C₃) con su punto de inicio y de fin.

Triángulo de vértices (0, 0), (1, 0), (0, 1). Antihorario: C₁ de (0, 0) a (1, 0); C₂ de (1, 0) a (0, 1); C₃ de (0, 1) a (0, 0).

Paso 3. Green

∮C P dx + Q dy = ∬D (∂Q/∂x − ∂P/∂y) dA

(a) Derivá Q respecto de x y P respecto de y. (b) Restá. (c) Integrá sobre D: si dio una constante k, es k · área. Si no, describí D: x entre dos números, y entre dos funciones (o polares si es un círculo).

∮ x dy − y dx sobre el triángulo: Q = x ⇒ ∂Q/∂x = 1. P = −y ⇒ ∂P/∂y = −1. Resta: 1 − (−1) = 2. Área del triángulo 1/2. Resultado 2 · 1/2 = 1.

7. Ecuaciones diferenciales de primer orden

Primero se despeja y′ y se identifica el tipo. Preguntate en este orden: ¿separable? ¿lineal? ¿exacta? ¿Bernoulli?

Separable: y′ = (algo de x) · (algo de y)

Pasos: (1) escribir y′ como dy/dx; (2) pasar todo lo de y con dy a la izquierda y lo de x con dx a la derecha; (3) integrar los dos lados; (4) una sola constante C; (5) despejar y si se puede; (6) si hay condición inicial, reemplazarla para sacar C.

y′ = x/y, y(0) = 2.

(1) dy/dx = x/y. (2) y dy = x dx. (3) y²/2 = x²/2 + C. (4)-(5) y² = x² + K (K = 2C). (6) 4 = 0 + K ⇒ K = 4. y = √(x² + 4) (raíz positiva porque y(0) = 2 > 0).

y′ = xy. dy/y = x dx ⇒ ln|y| = x²/2 + C ⇒ |y| = eC ex²/2 ⇒ y = K ex²/2.

Lineal: y′ + P(x) y = Q(x)

Pasos: (1) dejarla con y′ solo (coeficiente 1); (2) leer P y Q; (3) μ = e∫P dx, sin constante; (4) escribir (μ y)′ = μ Q; (5) integrar: μ y = ∫ μ Q dx + C; (6) dividir por μ.

x y′ + 2y = x² (x > 0).

(1) Divido por x: y′ + (2/x) y = x. (2) P = 2/x, Q = x. (3) ∫P = 2 ln x = ln x² ⇒ μ = x². (4) (x² y)′ = x² · x = x³. (5) x² y = x⁴/4 + C. (6) y = x²/4 + C/x².

Control: y′ = x/2 − 2C/x³; x y′ + 2y = x²/2 − 2C/x² + x²/2 + 2C/x² = x² ✓.

Exacta: M dx + N dy = 0 con ∂M/∂y = ∂N/∂x

Pasos: (1) leer M (lo que multiplica a dx) y N (a dy); (2) verificar My = Nx; (3) F = ∫ M dx + g(y), integrando en x con y constante; (4) derivar F respecto de y e igualar a N; (5) despejar g′(y) (no tiene que quedar x) e integrar; (6) la solución es F(x, y) = C.

(2xy + 1) dx + (x² + 3y²) dy = 0.

(1) M = 2xy + 1, N = x² + 3y². (2) My = 2x, Nx = 2x ✓. (3) F = x²y + x + g(y). (4) Fy = x² + g′(y) = x² + 3y². (5) g′ = 3y² ⇒ g = y³. (6) x²y + x + y³ = C.

Bernoulli: y′ + P y = Q yⁿ

Pasos: (1) identificar n; (2) cambio v = y1−n; (3) la ecuación queda v′ + (1 − n)P v = (1 − n)Q (lineal); (4) resolverla como lineal; (5) volver: y = v1/(1−n).

y′ + y = x y². (1) n = 2. (2) v = y⁻¹. (3) v′ + (1 − 2)·1·v = (1 − 2)x ⇒ v′ − v = −x. (4) μ = e−x: (v e−x)′ = −x e−x ⇒ v e−x = x e−x + e−x + C ⇒ v = x + 1 + C eˣ. (5) y = 1/(x + 1 + C eˣ).
