1. Definiciones

f tiene un máximo local en x₀ si existe un entorno B(x₀, r) tal que f(x) ≤ f(x₀) para todo x de ese entorno. Mínimo local: lo mismo con f(x) ≥ f(x₀).

Máximo (mínimo) absoluto en U: f(x) ≤ f(x₀) (≥) para todo x ∈ U.

x₀ es punto crítico si ∇f(x₀) = 0 o alguna derivada parcial no existe en x₀.

x₀ es punto de ensilladura si es crítico pero no es extremo: en todo entorno hay puntos con f mayor y puntos con f menor que f(x₀).

Local = gana en su barrio. Absoluto = gana en todo el dominio. Ensilladura = la silla de montar: subiendo en una dirección y bajando en otra.

2. Condición necesaria de extremo ★ (2023 y 2024)

Teorema
H)
f: U ⊂ ℝⁿ → ℝ tiene un extremo local en x₀, x₀ interior a U, y existen las derivadas parciales en x₀.
T)
∇f(x₀) = 0.

1. Supongo que es un máximo local (el mínimo es igual, con las desigualdades al revés).

2. Fijo una coordenada i y defino una función de una variable: g(t) = f(x₀ + t eᵢ). Es f restringida a la recta que pasa por x₀ en la dirección del eje i.

3. g está definida cerca de t = 0 porque x₀ es interior (hay una bola alrededor de x₀ dentro de U). Acá se usa esa hipótesis.

4. Como f(x) ≤ f(x₀) cerca de x₀, se cumple g(t) ≤ g(0) cerca de 0: g tiene un máximo local en t = 0.

5. g es derivable en 0 y g′(0) = límt→0 [f(x₀ + t eᵢ) − f(x₀)]/t = ∂f/∂xᵢ (x₀) (es exactamente la definición de derivada parcial; existe por hipótesis).

6. Por el teorema de Fermat en una variable (máximo local interior y derivable ⇒ derivada 0): g′(0) = 0, o sea ∂f/∂xᵢ (x₀) = 0.

7. Esto vale para cada i = 1, …, n: ∇f(x₀) = 0. ∎

Trampa 1: la recíproca es FALSA. f = x² − y² tiene ∇f(0, 0) = 0 y en (0, 0) hay una ensilladura (sobre el eje x sube, sobre el eje y baja).

Trampa 2: puede haber extremo donde las parciales no existen. f = √(x² + y²) (el cono) tiene mínimo en (0, 0) y ahí no existen las parciales. Por eso “punto crítico” incluye ese caso.

3. Fórmula de Taylor de segundo orden y Hessiana ★

Teorema de Taylor de 2.º orden (17/07/2024, 29/07/2022)
H)
f: U ⊂ ℝⁿ → ℝ de clase C³ en un abierto que contiene a x₀.
T)
f(x₀ + h) = f(x₀) + Σᵢ ∂f/∂xᵢ (x₀) hᵢ + ½ Σᵢ Σⱼ ∂²f/∂xᵢ∂xⱼ (x₀) hᵢ hⱼ + R₂(x₀, h), con R₂(x₀, h)/‖h‖² → 0 cuando h → 0.

En dos variables (h = Δx, k = Δy):

f(x₀ + h, y₀ + k) = f + fxh + fyk + ½ [fxxh² + 2fxyhk + fyyk²] + R₂, todo evaluado en (x₀, y₀).

Trampa: el 2 delante de fxy (porque aparecen fxyhk y fyxkh, que son iguales). Y el ½ adelante de todo el corchete.

Matriz Hessiana: H(x₀) = ( ∂²f/∂xᵢ∂xⱼ (x₀) ). En ℝ²: H = [[fxx, fxy], [fxy, fyy]]. Es simétrica por el teorema de Schwarz.

Forma matricial: f(x₀ + h) = f(x₀) + ∇f(x₀) · h + ½ hᵀ H(x₀) h + R₂.

Lectura: f cerca de x₀ es un número (la altura), más una parte lineal (el plano tangente, con el gradiente), más una parte cuadrática (la curvatura, con la Hessiana), más un resto despreciable. Es el polinomio de Taylor de una variable, en versión con vectores y matrices.

Ejemplo para fijar (de control)

f = eˣ cos y en (0, 0). f = 1; fx = eˣ cos y = 1; fy = −eˣ sen y = 0; fxx = 1; fxy = −eˣ sen y = 0; fyy = −eˣ cos y = −1.

P₂(x, y) = 1 + x + ½ (x² − y²). Control: eˣ ≈ 1 + x + x²/2 y cos y ≈ 1 − y²/2; multiplicando y quedándome con grado ≤ 2 sale lo mismo.

4. Condición suficiente: clasificar con la Hessiana ★

Teorema (17/07/2024, 29/07/2022, 22/11/2023)
H)
f de clase C³ cerca de x₀, x₀ punto crítico (∇f(x₀) = 0).
T)
Si H(x₀) es definida positiva, x₀ es un mínimo local. Si es definida negativa, máximo local. Si es indefinida, ensilladura.

Definida positiva: hᵀHh > 0 para todo h ≠ 0. Definida negativa: < 0 para todo h ≠ 0. Indefinida: toma valores positivos y negativos.

Demostración (caso mínimo; los otros son iguales):

1. Taylor en un punto crítico: como ∇f(x₀) = 0, el término lineal se va: f(x₀ + h) − f(x₀) = ½ hᵀHh + R₂. El signo de la izquierda dice si f sube o baja al moverme de x₀.

2. Como H es definida positiva, existe m > 0 con ½ hᵀHh ≥ m‖h‖² (la forma cuadrática es continua y positiva sobre la esfera ‖h‖ = 1, que es compacta: ahí tiene un mínimo positivo; después se escala por ‖h‖²).

3. Como R₂/‖h‖² → 0, existe δ tal que ‖h‖ < δ ⇒ |R₂| < m‖h‖². Uso la definición de límite con ε = m.

4. Entonces, para 0 < ‖h‖ < δ: f(x₀ + h) − f(x₀) ≥ m‖h‖² − |R₂| > 0.

5. f(x₀ + h) > f(x₀) cerca de x₀: mínimo local (estricto). ∎

Si es indefinida: hay una dirección h₁ con h₁ᵀHh₁ > 0 (ahí f sube) y otra h₂ con h₂ᵀHh₂ < 0 (ahí f baja), tomando t·h₁ y t·h₂ con t chico. Eso es una ensilladura.

El criterio práctico en dos variables (de dónde sale)

Con a = fxx, b = fxy, c = fyy y a ≠ 0, completando cuadrados:

a h² + 2b hk + c k² = a [ (h + (b/a) k)² + ((ac − b²)/a²) k² ]

Desarrollá la derecha para comprobarlo: a(h² + 2(b/a)hk + (b²/a²)k²) + ((ac − b²)/a) k² = ah² + 2bhk + ck².

Con D = ac − b² = det H: si D > 0, el corchete es suma de dos cosas positivas (para (h, k) ≠ 0), y el signo de todo es el de a. Si D < 0, con k = 0 da el signo de a, y con h = −(b/a)k da (D/a)k², de signo contrario: toma los dos signos.

Trampa del D = 0: x⁴ + y⁴ tiene mínimo en el origen, −x⁴ − y⁴ máximo y x⁴ − y⁴ ensilladura, y en los tres D = 0. Hay que estudiar f cerca del punto.

En n variables (criterio de Sylvester), con los menores principales Δ₁, Δ₂, …, Δₙ de H: todos positivos ⇒ definida positiva (mínimo). Signos alternados empezando negativo (Δ₁ < 0, Δ₂ > 0, Δ₃ < 0…) ⇒ definida negativa (máximo). det H ≠ 0 y ninguno de los dos patrones ⇒ ensilladura.

5. Extremos absolutos (miércoles 11)

Teorema de Weierstrass: si f es continua en un conjunto compacto (cerrado y acotado), alcanza un máximo y un mínimo absolutos.

Procedimiento: 1) puntos críticos del interior; 2) extremos sobre la frontera (con Lagrange o parametrizando el borde); 3) evaluar f en todos los candidatos y comparar.

Ya no hace falta la Hessiana: alcanza con comparar valores, porque Weierstrass garantiza que el máximo y el mínimo están entre los candidatos.

6. Multiplicadores de Lagrange ★ (07/12/2022, miércoles 11)

Teorema
H)
f y g de clase C¹; x₀ es extremo de f restringida a S = {g(x) = c}; ∇g(x₀) ≠ 0.
T)
Existe λ ∈ ℝ tal que ∇f(x₀) = λ ∇g(x₀).

Por qué vale (la idea que se escribe):

1. Tomo cualquier curva γ(t) contenida en S con γ(0) = x₀.

2. Como g(γ(t)) = c para todo t, derivo con la regla de la cadena: ∇g(x₀) · γ′(0) = 0. ∇g es perpendicular a todo vector tangente a S.

3. Como f(γ(t)) tiene un extremo en t = 0, su derivada ahí es 0: ∇f(x₀) · γ′(0) = 0. ∇f también es perpendicular a todo vector tangente a S.

4. Los dos gradientes son perpendiculares al mismo espacio tangente: son paralelos, ∇f(x₀) = λ∇g(x₀). ∎ Hace falta ∇g ≠ 0 para que el espacio tangente sea el correcto.

Método: resolver el sistema ∇f = λ∇g, g = c (n + 1 ecuaciones con n + 1 incógnitas: x₁, …, xₙ, λ). Evaluar f en las soluciones; si S es compacto, el mayor valor es el máximo y el menor el mínimo. Con dos restricciones: ∇f = λ∇g + μ∇h.

Interpretación geométrica: en el extremo, la curva de nivel de f que pasa por x₀ es tangente a la curva de restricción g = c. Si la cortara, moviéndome sobre la restricción pasaría a niveles de f más altos de un lado y más bajos del otro, y no sería extremo. Tangentes ⇔ gradientes paralelos.

λ mide cuánto cambia el valor óptimo de f si cambio un poco c.
