Si te trabás en un ejercicio, a los 25 minutos lo dejás y pasás al siguiente. Con tres ejercicios bien hechos estás en 75%, que es un 7. Con dos, estás en 50% y desaprobás. El final se gana no dejando ninguno en blanco.

Modelo oficial. 2 de julio de 2025

Fuente: fuentes/AM2-Modelo-final-practico-2025-07-02.pdf. Evaluación final práctica, 120 min.

Ejercicio 1. La función partida

f(x, y) = xy / √(x² + y²) si (x, y) ≠ (0, 0), y f(0, 0) = 0.

a) Es continua en (0,0). En polares, x = r cos θ, y = r sen θ:

f = (r cos θ · r sen θ) / r = r cos θ sen θ = (r/2) sen(2θ).

El módulo es ≤ r/2, que tiende a 0 cuando r → 0, para cualquier θ. El límite es 0, que es f(0,0). Continua.

b) Parciales por definición.

∂f/∂x (0,0) = límh→0 [f(h, 0) − 0] / h = 0, porque f(h, 0) = 0.

∂f/∂y (0,0) = límk→0 [f(0, k) − 0] / k = 0, porque f(0, k) = 0.

c) No es diferenciable. El candidato a diferencial es el gradiente (0, 0). Hay que ver si

lím(h,k)→(0,0) f(h, k) / √(h² + k²) = 0.

Ese cociente es |cos θ sen θ| = |sen(2θ)| / 2. Sobre y = x vale 1/2, sobre los ejes vale 0. No existe el límite. No es diferenciable.

El molde, para cualquier f que te pongan: polares para la continuidad. Parciales solo sobre los ejes. Para la diferenciabilidad, el cociente [f − f(0) − fx h − fy k] / r tiene que ir a 0 en toda dirección. Si depende de θ, listo, no es diferenciable.

Ejercicio 2. Extremos libres

f(x, y) = x³ + y² − 3x − 4y.

∂f/∂x = 3x² − 3 = 0 ⇒ x² = 1 ⇒ x = ±1.

∂f/∂y = 2y − 4 = 0 ⇒ y = 2.

Puntos críticos: (1, 2) y (−1, 2).

∂²f/∂x² = 6x, ∂²f/∂y² = 2, ∂²f/∂x∂y = 0. Hessiano H = 12x.

Ejercicio 3. Volumen en polares

1 ≤ z ≤ 2 − √(x² + y²), con x ≥ 0.

El techo toca el piso cuando 2 − r = 1, o sea r = 1. La región del plano es el semicírculo derecho r ≤ 1, θ de −π/2 a π/2.

Volumen = ∬D (1 − r) dA = ∫−π/2π/2 ∫01 (1 − r) r dr dθ.

La integral en r: [r²/2 − r³/3]01 = 1/2 − 1/3 = 1/6.

La integral en θ vale π. Volumen = π/6.

El error típico es integrar (1 − r) sin el jacobiano r, o tomar θ de 0 a 2π cuando el enunciado dice x ≥ 0.

Ejercicio 4. Green y directa

∮C y dx + 2x dy, con C la frontera positiva de 1 − x² ≤ y ≤ 1, 0 ≤ x ≤ 1.

Green. P = y, Q = 2x. ∂Q/∂x − ∂P/∂y = 2 − 1 = 1.

∮ = ∬D 1 dA = ∫01 [1 − (1 − x²)] dx = ∫01 x² dx = 1/3.

Directa, orientación antihoraria. La región queda a la izquierda.

  1. Parábola y = 1 − x², x de 0 a 1, dy = −2x dx. ∫ (1 − x² − 4x²) dx = ∫01 (1 − 5x²) dx = 1 − 5/3 = −2/3.
  2. Segmento x = 1, y de 0 a 1, dx = 0. ∫ 2 dy = 2.
  3. Segmento y = 1, x de 1 a 0, dy = 0. ∫10 1 dx = −1.

Suma: −2/3 + 2 − 1 = 1/3. Coincide con Green. Si no coincide, la orientación está al revés: cambiá el signo de los tres tramos.

Práctica Einstein 2026

Fuente: fuentes/AM2-Final-2026-Einstein.pdf. Mismos cuatro moldes, uno de ellos es una ecuación diferencial.

1. Otra función partida

F(x, y) = 3x y² / (x² + y²) si (x, y) ≠ 0, y 0 en el origen.

Continua: |F| ≤ 3|x| · 1 → 0. Parciales en el origen: F(h, 0) = 0 y F(0, k) = 0, así que las dos valen 0.

No diferenciable: F/r = 3 |cos θ| sen² θ. En θ = π/4 vale 3√2/4 ≠ 0, en los ejes vale 0. El límite no es 0.

2. Extremos sobre la circunferencia

F = xy sobre x² + y² = 4. Lagrange: ∇F = λ ∇g, con g = x² + y² − 4.

(y, x) = λ (2x, 2y). Entonces y = 2λx y x = 2λy, de donde x² = y². Sobre la circunferencia, |x| = |y| = √2.

PuntoF = xy
(√2, √2) y (−√2, −√2)2, máximo
(√2, −√2) y (−√2, √2)−2, mínimo

El conjunto es cerrado y acotado, así que estos valores son los extremos globales.

3. Integral doble con parámetro

F = |x| y. R es la unión de dos triángulos: a la izquierda, 0 ≤ y ≤ λx + 3 con −3/λ ≤ x ≤ 0; a la derecha, 0 ≤ y ≤ 3 − x con 0 ≤ x ≤ 3. λ > 0. Piden λ tal que la integral valga 9/2.

A la derecha |x| = x:

∫03 x · (1/2) (3 − x)² dx = 27/8.

A la izquierda |x| = −x. El cambio u = λx + 3 deja

27 / (8λ²).

27/8 + 27/(8λ²) = 9/2 ⇒ 1 + 1/λ² = 4/3 ⇒ λ = √3.

4. Ecuación de segundo orden

y″ − 4y = e2x, con y(0) = 1, y′(0) = 1/3.

Característica: r² − 4 = 0, r = ±2. Homogénea: C₁ e2x + C₂ e−2x.

El e2x ya está en la homogénea, así que la particular es A x e2x. Al derivar dos veces y restar 4y queda 4A e2x. Entonces A = 1/4.

y = C₁ e2x + C₂ e−2x + (x/4) e2x.

y(0): C₁ + C₂ = 1.

y′(0): 2C₁ − 2C₂ + 1/4 = 1/3 ⇒ C₁ − C₂ = 1/24.

C₁ = 25/48, C₂ = 23/48.

Coeficientes indeterminados, los tres casos.

y″ + ay′ + by = lado derecho.

  1. Polinomio de grado n: particular del mismo grado. Si r = 0 es raíz simple, multiplicá por x. Si es doble, por x².
  2. eαx: particular A eαx. Si α es raíz, A x eαx. Si es raíz doble, A x² eαx.
  3. cos(βx) o sen(βx): A cos(βx) + B sen(βx). Si ±iβ son raíces, multiplicá todo por x. Es el caso y″ + 4y = cos(2x): la particular es (x/4) sen(2x).

El otro final de Einstein, en corto

Fuente: fuentes/AM2-Final-Einstein.pdf.

1. f = |x|² y / (x² + y²) = x² y / (x² + y²). |f| ≤ |y| → 0, continua. Parciales en el origen: 0. El cociente f/r = |cos² θ sen θ| no tiende a 0 (en θ = π/2 vale 0, en θ = π/4 vale √2/4). No diferenciable.

2. f = x² + 2y² sujeta a (x − 1)² + 2y² = 1. Lagrange: (2x, 4y) = λ (2(x − 1), 4y).

De la segunda coordenada, 4y = λ 4y, así que y = 0 o λ = 1.

Si y = 0: (x − 1)² = 1, x = 0 o x = 2. f(0, 0) = 0, f(2, 0) = 4.

Si λ = 1: 2x = 2(x − 1), que da 0 = −2, imposible. No hay más puntos.

Mínimo global 0 en (0, 0). Máximo global 4 en (2, 0).

Derivada direccional, el reemplazo del ejercicio 2

Fuente: fuentes/AM2-Final-2025-Einstein.pdf. f(x, y, z) = x² y + ln(z) + y z² en (1, 1, 1), dirección u = (√3/2, 0, 1/2). Ya es unitario: (√3/2)² + (1/2)² = 1.

∇f = (2xy, x² + z², 1/z + 2yz). En el punto: (2, 2, 3).

Direccional = ∇f · u = 2·(√3/2) + 0 + 3·(1/2) = √3 + 3/2.

Máxima razón de cambio = ‖∇f‖ = √(4 + 4 + 9) = √17, en la dirección del gradiente.

En ese mismo PDF el volumen es 0 ≤ z ≤ 4 − x² − y² con x² + y² ≤ x. Completando el cuadrado, el disco es (x − 1/2)² + y² ≤ 1/4. En polares conviene dejarlo como r ≤ cos θ, con θ de −π/2 a π/2 (porque r ≥ 0 exige cos θ ≥ 0).

V = ∫−π/2π/2 ∫0cos θ (4 − r²) r dr dθ = ∫−π/2π/2 [2 cos² θ − (1/4) cos⁴ θ] dθ.

cos² θ = (1 + cos 2θ)/2, así que el primer término integra π en ese intervalo. cos⁴ θ = (3 + 4 cos 2θ + cos 4θ)/8 integra 3π/8. Queda π − (1/4)·(3π/8) = 29π/32.

El campo de ese PDF es F = (2xy, x²). ∂Q/∂x − ∂P/∂y = 2x − 2x = 0, así que Green da 0 y el campo es conservativo: potencial φ = x² y.

Unicidad del límite

Si el límite existe, es único. Supongamos dos límites b₁ ≠ b₂. Para ε > 0 hay δ₁ y δ₂. Con δ = min(δ₁, δ₂) y un punto a distancia menor que δ,

|b₁ − b₂| ≤ |b₁ − f| + |f − b₂| < 2ε.

Eso vale para todo ε > 0. Tomando ε = |b₁ − b₂|/2 se llega a |b₁ − b₂| < |b₁ − b₂|, absurdo.

Direccional = gradiente por u

Si f es diferenciable en x₀ y u es unitario, la direccional es el límite de [f(x₀ + t u) − f(x₀)] / t.

Por diferenciabilidad, f(x₀ + t u) − f(x₀) = ∇f · (t u) + ε(t) |t|, con ε(t) → 0. Dividiendo por t queda ∇f · u + ε(t) · (signo), que tiende a ∇f · u.

Necesaria para un extremo libre

Si x₀ es extremo local interior y existen las parciales, entonces ∇f(x₀) = 0.

La función de una variable g(t) = f(x₀ + t eᵢ) tiene extremo en t = 0, así que g′(0) = 0. Pero g′(0) es la parcial respecto de xᵢ. Todas las parciales se anulan.

Green, el enunciado que hay que soltar de una

Si P y Q tienen parciales continuas en un dominio simplemente conexo que contiene a D, y C es el borde de D orientado en positivo,

∮C P dx + Q dy = ∬D (∂Q/∂x − ∂P/∂y) dA.
