El final del 1/2/2024, resuelto

1. Máximo por la secante, error 10⁻³

La función de la consigna está en la imagen del enunciado y no se lee en la copia. El método es siempre el mismo: un máximo es una raíz de f′. Se aplica la secante a g(x) = f′(x), y después se verifica que f″ < 0 (o que f crece antes y decrece después).

xn+1 = xn − g(xn) · (xn − xn−1) / (g(xn) − g(xn−1))

Ejemplo para practicar: máximo de f(x) = x e−x. g(x) = f′(x) = e−x(1 − x). x₀ = 0,5, x₁ = 1,5.

3. Eliminación gaussiana

7x₁ − 3x₂ + 3x₃ = 8; 2x₁ − 3x₂ − 10x₃ = 6; 3x₁ − 8x₂ + 12x₃ = 8. Resolver y explicar qué pasa con la solución.
Resolución

Pivote 7. m₂₁ = 2/7 = 0,285714; m₃₁ = 3/7 = 0,428571.

F₂ ← F₂ − m₂₁F₁: [0; −2,142857; −10,857143 | 3,714286]. F₃ ← F₃ − m₃₁F₁: [0; −6,714286; 10,714286 | 4,571429].

Con pivoteo parcial convendría usar −6,714286 de pivote (es el mayor en módulo); sin pivoteo: m₃₂ = −6,714286/−2,142857 = 3,133333.

F₃ ← F₃ − m₃₂F₂: [0; 0; 44,733333 | −7,066667].

Sustitución hacia atrás: x₃ = −7,066667/44,733333 = −0,1580. x₂ = (3,714286 + 10,857143 · x₃)/(−2,142857) = −0,9329. x₁ = (8 + 3x₂ − 3x₃)/7 = 0,8107.

Exactos: x₁ = 544/671, x₂ = −626/671, x₃ = −106/671. El determinante es 7 · (−2,142857) · 44,733333 = −671 ≠ 0: sistema compatible determinado, solución única. Verificación en la ecuación 1: 7 · 0,8107 + 3 · 0,9329 − 3 · 0,1580 = 8,000.

Qué decir en cada caso: si queda una fila 0 = 0, infinitas soluciones (compatible indeterminado); si queda 0 = c ≠ 0, no tiene solución (incompatible).

Sistemas lineales

Directos: Gauss (triangular superior y sustitución hacia atrás), Gauss-Jordan (hasta la identidad), con pivoteo parcial (en cada columna, pivote de mayor módulo, para reducir el error de redondeo).

Iterativos: Jacobi: xi(k+1) = [bi − Σj≠i aij xj(k)]/aii. Gauss-Seidel: igual, pero usando los valores nuevos apenas se calculan (converge más rápido). Convergen si la matriz es diagonalmente dominante: |aii| > Σj≠i|aij|. Si no lo es, reordená las ecuaciones antes de empezar.

Ajuste de curvas (regresión)

Recta por mínimos cuadrados y = a₀ + a₁x: a₁ = (nΣxy − ΣxΣy)/(nΣx² − (Σx)²), a₀ = ȳ − a₁x̄.

Calidad: Sr = Σ(yi − a₀ − a₁xi)², St = Σ(yi − ȳ)², r² = (St − Sr)/St. Error estándar sy/x = √(Sr/(n − 2)).

Linealizaciones: y = a ebx → ln y = ln a + bx. y = a xb → log y = log a + b log x. Polinomial: ecuaciones normales con Σxᵏ.

Interpolación

Newton con diferencias divididas: P(x) = f[x₀] + f[x₀,x₁](x − x₀) + f[x₀,x₁,x₂](x − x₀)(x − x₁) + … Ventaja: agregar un punto suma un término sin rehacer todo. Grado: si las diferencias de orden k son constantes, alcanza grado k.

Lagrange: P(x) = Σ yi Li(x), Li(x) = Πj≠i (x − xj)/(xi − xj).

Error: f(x) − Pn(x) ≈ f[x₀,…,xn, x] Π(x − xi); se estima con la diferencia del siguiente orden.

Ecuaciones diferenciales ordinarias

y′ = f(x, y), y(x₀) = y₀, paso h.

Euler: yn+1 = yn + h f(xn, yn). Error global O(h).

Euler mejorado (Heun, RK2): y* = yn + h f(xn, yn); yn+1 = yn + (h/2)[f(xn, yn) + f(xn+1, y*)].

Runge-Kutta 4: k₁ = f(xn, yn); k₂ = f(xn + h/2, yn + hk₁/2); k₃ = f(xn + h/2, yn + hk₂/2); k₄ = f(xn + h, yn + hk₃); yn+1 = yn + (h/6)(k₁ + 2k₂ + 2k₃ + k₄). Error global O(h⁴).

Para practicar: y′ = x + y, y(0) = 1, h = 0,1, un paso con Euler y con RK4. Exacta: y = 2ex − x − 1.
Resolución

Euler: y₁ = 1 + 0,1 · 1 = 1,1.

RK4: k₁ = 1; k₂ = f(0,05; 1,05) = 1,1; k₃ = f(0,05; 1,055) = 1,105; k₄ = f(0,1; 1,1105) = 1,2105. y₁ = 1 + (0,1/6)(1 + 2,2 + 2,21 + 1,2105) = 1,110342.

Exacta: 2e0,1 − 1,1 = 1,110342. Euler erra 0,0103; RK4 erra menos de 10⁻⁶.
